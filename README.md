## User Story

I 3D print pet tags, wanted to spin up a quick customiser and see if the 3D printed texture could be replicated with Three.js and webGL. ChatGPT re-created the texture with a precedural height map that works even with the changing text. Might change the server to a normal express server and not store geometry, or I'll include an option to download geometry if users will print it themselves. Keeping ChatGPT's generator.py script for now.

## Installation

1. Clone the repo to your computer by clicking the green code button and copying the SSH version.

2. Open Gitbash in your desired folder and type `git clone ` then right click to paste the string and hit enter. The repo will then be cloned to your computer.

3. Navigate to the repo folder and type `code .` into gitbash to open the repo in VS Code.

4. Open a new Terminal in VS Code and type `npm install` to install the repo dependencies.
